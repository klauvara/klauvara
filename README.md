# Web de Klauvara

Web personal de Claudia Fernández (@klauvara). HTML, CSS y JS sin dependencias.

## Estructura
- `index.html`: todo el contenido (textos, enlaces)
- `styles.css`: colores y diseño (los colores están arriba del todo, en `:root`)
- `script.js`: menú del móvil y botón de copiar email
- `img/`: imágenes

## Cambiar las imágenes
Sustituye los archivos de `img/` por otros **con el mismo nombre**:
- `claudia.jpg`: foto del inicio (vertical 4:5)
- `video-1.jpg`, `video-2.jpg`, `video-3.jpg`: miniaturas de YouTube (1280×720)
- `og-image.jpg`: imagen que sale al compartir el enlace (1200×630)
- `favicon.png`: el logo k. de la pestaña del navegador

## Publicar en GitHub Pages
1. Sube todos los archivos a la raíz del repositorio (con la carpeta `img`).
2. Settings → Pages → Source: `Deploy from a branch` → rama `main`, carpeta `/ (root)` → Save.
3. Web: https://klauvara.github.io/klauvara/
