# Web de Klauvara

Web personal de Claudia Fernández (@klauvara). HTML, CSS y JS sin dependencias.

## Estructura
- `index.html`: todo el contenido (textos, enlaces)
- `styles.css`: colores y diseño (los colores están arriba del todo, en `:root`)
- `script.js`: menú del móvil y botón de copiar email
- `img/`: imágenes

## Cambiar las imágenes
Sustituye los archivos de `img/` por los tuyos **con el mismo nombre**:
- `claudia.jpg`: tu foto, vertical 4:5 (por ejemplo 1000×1250)
- `video-1.jpg`, `video-2.jpg`, `video-3.jpg`: miniaturas de YouTube (1280×720)
- `og-image.jpg`: la imagen que sale al compartir el enlace (1200×630)

## Cosas pendientes de poner
1. En `index.html`, busca `TU-USUARIO` y pon tu enlace real de LinkedIn.
2. Cambia los tres `href` de los vídeos por los enlaces reales de cada vídeo.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `klauvara`).
2. Sube todos los archivos (Add file → Upload files), con la carpeta `img` incluida.
3. Ve a Settings → Pages → Source: `Deploy from a branch` → rama `main`, carpeta `/ (root)` → Save.
4. En un par de minutos estará en `https://TU-USUARIO-GITHUB.github.io/klauvara/`.

Si más adelante compras un dominio (p. ej. `klauvara.com`), se conecta en la misma pantalla de Pages, en "Custom domain".
